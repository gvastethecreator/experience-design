# Experience Design

Agent Skill for UX research and journey design. It turns a usage problem into a testable decision: task, evidence, hypothesis, design, then proof.

## Quick start

```text
npx skills add gvastethecreator/experience-design
```

Copy `SKILLS/experience-design` into the skill directory your agent already loads. Modes: `assess`, `design`, `experiment`, `verify`, `apply`.

See [SKILL.md](SKILLS/experience-design/SKILL.md). Optional routing to other skills is listed in [ecosystem-routing.md](SKILLS/experience-design/references/ecosystem-routing.md); those skills are used only when available.
